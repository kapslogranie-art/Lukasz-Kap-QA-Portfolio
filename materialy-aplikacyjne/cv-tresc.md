## Podsumowanie

Początkujący tester manualny z praktycznym warsztatem pełnego cyklu testów: analiza wymagań,
projektowanie przypadków testowych, testy funkcjonalne, regresyjne i eksploracyjne, raportowanie
błędów w Jira oraz retesty. Znam podstawy testów API (Postman), SQL i automatyzacji
(Python, PyTest, Selenium). Na co dzień wykorzystuję narzędzia AI do analizy wymagań
i przygotowania testów — zawsze z weryfikacją wyników. Dokładny, konsekwentny, komunikatywny.

## Umiejętności

**Testowanie manualne**
- Analiza wymagań, user stories i kryteriów akceptacji; zadawanie pytań doprecyzowujących
- Projektowanie przypadków testowych: klasy równoważności, wartości brzegowe, tablice decyzyjne,
  przejścia stanów
- Testy funkcjonalne, regresyjne, eksploracyjne (sesje z kartą testu), smoke, UI/UX, walidacje formularzy
- Testy aplikacji webowych w wielu przeglądarkach; testy responsywności (Chrome DevTools, tryb urządzeń)
- Raportowanie defektów: kroki, wynik oczekiwany/rzeczywisty, priorytet, ważność, załączniki, retest

**Narzędzia**
- Jira (zgłoszenia, workflow), Xray, TestLink, TestRail (struktura przypadków i import CSV), Bugzilla
- Postman (REST, JSON, kody HTTP, testy w zakładce *Tests*), Chrome DevTools (Network, Console), JMeter (podstawy)
- SQL (Microsoft SQL Server / T-SQL): SELECT, WHERE, JOIN, GROUP BY, HAVING, transakcje — weryfikacja danych
- Oracle SQL Developer, PyCharm, ShareX, Git / GitHub, GitHub Actions (CI — automatyczne uruchamianie testów), Newman

**Automatyzacja (podstawy)**
- Python, unittest, PyTest (fixtures, parametrize, conftest), Selenium WebDriver, Page Object Model
- Uruchamianie i utrzymanie prostych testów: aktualizacja lokatorów, analiza przyczyny niepowodzenia

**AI w pracy testera**
- Wykorzystanie asystentów AI (m.in. Claude Code) do analizy wymagań, generowania szkiców przypadków
  testowych i danych testowych, porządkowania raportów błędów
- Świadomość ograniczeń: weryfikacja wyników, brak przekazywania danych poufnych do narzędzi AI

**Metodyki:** SDLC, STLC, Agile/Scrum (sprinty, daily, refinement, Definition of Done)
