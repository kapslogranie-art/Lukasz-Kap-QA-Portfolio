## Przykładowy bug report po angielsku

```
Title: [Checkout] Last Name input is written into First Name field (problem_user)
Environment: https://www.saucedemo.com, Chrome, Windows 11
Steps to reproduce:
  1. Log in as problem_user / secret_sauce
  2. Add any product to the cart and click Checkout
  3. Type "Jan" in First Name
  4. Type "Kowalski" in Last Name
Expected result: First Name = "Jan", Last Name = "Kowalski"
Actual result: Text typed in Last Name appears in First Name. Last Name stays empty.
               "Error: Last Name is required" is shown. The order cannot be completed.
Severity: Critical   Reproducibility: 5/5
```
